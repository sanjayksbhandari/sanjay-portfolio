# Sanjay Singh Bhandari — Engineering Portfolio
## Documentation Set (Phase 0: Planning Only — No Code)

This folder is the single source of truth for the design and build of a
world-class engineering portfolio for **Sanjay Singh Bhandari**, Senior Java
Engineering Leader (17+ years). Nothing in this set is speculative marketing
copy — it is a working specification a small engineering + design team could
hand off and build from without further clarification (except where explicit
`[NEEDS INPUT FROM SANJAY]` markers are used, because we do not invent facts).

## Positioning (one sentence)

> A portfolio that reads like a well-run production system: clear ownership,
> documented decisions, no noise — proof that the person who built it also
> builds the software recruiters are hiring for.

## How to use this set

Read in order for a full mental model, or jump directly to the document you
need. Every later phase (visual design, component build, content writing)
must trace back to a decision recorded here. If a future decision
contradicts a document in this set, update the document — don't silently
diverge.

## Non-negotiable constraints carried through every document

1. **No invented facts.** Companies, projects, technologies, and
   certifications are limited to the verified list. Any performance metric,
   team size, or outcome number not explicitly supplied by Sanjay is marked
   `[METRIC NEEDED]` rather than fabricated.
2. **No AI-portfolio clichés.** No particle backgrounds, no skill percentage
   bars, no glassmorphism, no gradient overload, no typing effects, no
   floating logos, no fake terminals.
3. **Typography and whitespace are the design system**, not decoration on
   top of one.
4. **One accent color.** Everything else is neutral grayscale + white.
5. **Every animation must justify its existence** against the checklist in
   document 16 or it is cut.
6. **Every section must answer a specific recruiter/hiring-manager
   question** — see document 05 for the full question map.
